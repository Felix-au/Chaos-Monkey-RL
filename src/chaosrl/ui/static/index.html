Simulated Microservice Architecture & Gymnasium Model

Visualizing the 3-Layer DAG Topology, Multi-Tenant Node Placement, 61-Dim Observation Space, Action Masking, and Rewards.

1. Three-Layer Microservice DAG Topology

Discrete-Time Dynamics
Layer 0: Gateway Layer (Ingress Entrypoints)

Receives external requests (baseline load + diurnal sine wave + noise). Evaluates Gateway p99 Latency (<300ms) and Error Rate (<5%) for system-wide SLO violations.

↓ Forward Requests / ↑ Cascading Timeouts & Error Propagation
Layer 1: Business Logic Layer (~55% of Services)

Executes domain workflows. Configured with timeouts (150–5000ms), max retries (0–3), exponential backoff, circuit breakers (trip on >40% failure), and fallback caches.

↓ Dependency RPC Calls / ↑ Retry Storm Amplification
Layer 2: Data & Backend Tier (~40% of Services)

Storage databases, caches, and heavy-tailed hub services. High fan-in from business services. Vulnerable to single-replica capacity saturation.

2. Multi-Tenant Infrastructure & Node Co-location

Physical Nodes (M=5 to 40)

Services consist of 1 to $R$ replicas distributed across $M$ physical/virtual nodes. Unrelated services share nodes.

Node N_0 (Physical Server Host)
svc_0 (Gateway Rep 0) svc_3 (Hub Data Rep 0) svc_7 (Auth Business Rep 0)
Correlated Co-location Hazard: Injecting NODE_FAILURE on N_0 simultaneously kills replicas of all three services, triggering correlated multi-service degradation!

4. Factored Action Space & Invalid Action Masking

sb3-contrib MaskablePPO

Discrete action space mapped to (Target Service/Node, Fault Type, Intensity).

Action #0 (POD_KILL on svc_0) TRUE (Valid)
Action #5 (NODE_FAIL on node_0) FALSE (Already Tried)
Action #12 (LATENCY on svc_3) TRUE (Valid)

action_masks() zeroes out logits for invalid/tested actions, preventing RL policy from wasting budget on redundant fault injections.

5. Reward Formulations (R1, R2, R3 Safety Engineering)

Safety-Constrained Chaos
R1: Pure Novelty
R = \text{Newly Found Weaknesses}

Maximizes discoveries but ignores collateral damage, learning to crash the gateway repeatedly.

R2: Safety-Constrained (Primary)
R = \text{Newly Found} - 0.15 \times \text{Damage}

Optimal tradeoff: rewards weakness discovery while penalizing SLO-violation time and error budget consumption.

R3: Safety + Curiosity
R = R_2 - \text{Repeat Penalty} + \text{Info Bonus}

R2 minus penalty for repeating actions plus small bonus for probing sub-SLO degradation.
