# ChaosRL: Reinforcement Learning for Microservice Resilience & Chaos Engineering

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![Gymnasium](https://img.shields.io/badge/Gymnasium-v1.0+-green.svg)](https://gymnasium.farama.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **Research Question:** Can a reinforcement learning agent discover more weaknesses in a microservice system, using fewer fault-injection experiments and causing less damage, than (a) Chaos Monkey-style random injection, (b) a scripted round-robin sweep, and (c) a multi-armed bandit?

Traditional chaos engineering (e.g. Netflix Chaos Monkey) randomly terminates instances with no memory and cannot reason about cascading failures, latency spikes, or compound bottlenecks. **ChaosRL** introduces a sample-efficient, safety-constrained reinforcement learning framework (`MaskablePPO`) to systematically identify latent architectural vulnerabilities with minimal collateral system damage.

---

## Key Features

- **High-Throughput Discrete-Time Simulator:** Capable of simulating 20 to 500 microservices with layered DAG topologies, physical/virtual node placement, M/M/c queueing dynamics, cascading timeouts, retry storms, and circuit breakers. Benchmarked at **>15,000 experiments/min** on CPU for 100-service systems.
- **Planted Ground-Truth Weaknesses:** Deterministically planted single vulnerabilities (single-replica hubs, unbounded timeouts, missing circuit breakers, correlated co-location) and compound multi-fault vulnerabilities (downstream latency + upstream retries, multi-pod stress).
- **Gymnasium Compliant (`ChaosEnv`):** Features scale-invariant 61-dimensional observation spaces and action masking (`sb3-contrib.MaskablePPO`) to enable zero-shot transfer across system scales.
- **Fair Baseline Comparison:** Evaluates Chaos Monkey, Random-All, Round-Robin, and Multi-Armed Bandit (UCB & Epsilon-Greedy) under identical budgets on strictly held-out test systems.
- **Empirical Grounding:** Real-data calibration using 735 traces from the public **RCAEval** benchmark (Online Boutique, Sock Shop, Train Ticket).
- **Strict Integrity:** 100% of reported numbers, confidence intervals, p-values, tables, and figures are dynamically generated by real runs. Zero hardcoded results.

## Quickstart & Installation

### 1. Environment Setup

```bash
# Clone repository
git clone https://github.com/your-username/chaosrl.git
cd chaosrl

# Install dependencies
pip install -r requirements.txt
pip install -e .
```

### 2. Run Test Suite

```bash
make test
# or: python -m pytest tests/ -v
```

### 3. Quick Mode (Finishes in ~2 minutes)

```bash
make quick
# Runs evaluation on small systems with 5 seeds, generates summary tables and plots
```

### 4. Full Benchmark Pipeline

```bash
make all
# 1. Downloads & calibrates against RCAEval traces
# 2. Trains MaskablePPO across 5 seeds
# 3. Evaluates all baselines across 20, 100, 300 service scales
# 4. Generates statistical significance tests, ablations, figures, and REPORT.md
```
